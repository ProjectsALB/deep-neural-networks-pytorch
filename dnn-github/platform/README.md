# Deep Neural Networks me PyTorch (platformë mësimore)
Faqe statike: HTML, CSS, JavaScript. Hyrja kërkon fjalëkalim (ruhet si hash në `js/gate.js`).
Publikimi në Netlify: "Add new site" > "Deploy manually", tërhiq folderin `platform`.
Përmbajtja: `js/data.js` (modulet), `js/code.js` (kodi i materialit). Për të ndryshuar fjalëkalimin, zëvendëso H1 dhe H2 në `js/gate.js` me SHA-256 dhe djb2 të fjalëkalimit të ri.
